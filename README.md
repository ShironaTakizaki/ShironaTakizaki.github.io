# 脱属人化 — 滝咲白菜 / Shirona Takizaki

> 「あの人だからできる」を、「なぜできるか」から組み直す。

性質表現に頼らず、判断の理由を検討できる形へ組み直す仕事を示す、滝咲白菜のポートフォリオです。

公開サイト: <https://shironatakizaki.github.io/>

## 状態

このサイトは検証前の静的プロトタイプです。公開文章、判断構造、三つの実例、受付画面を確認できますが、第三者の理解、需要、到達、実例の効果はまだ検証していません。

受付画面へ入力した内容は、送信、保存されません。問い合わせ受付、利用者アカウント、パスワード処理、決済、アクセス解析は実装していません。

## 構成

- `index.html`: 公開ページ
- `styles.css`: ライト／ダーク対応の表示定義
- `app.js`: 実例詳細と受付画面の段階表示
- `why-details.js`: 公開する「なぜ？」詳細データ

外部ランタイム、パッケージ管理、ビルド工程はありません。

## ローカル確認

Python 3が利用できる環境では、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 8000
```

その後、<http://localhost:8000/>を開きます。
